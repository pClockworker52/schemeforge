# Cold spray: pre-registration of the retrospective zoo test (v1)

Frozen 2026-11-03, committed **before** any score was computed. The scoring commit must come after this one;
`git log` is the proof of order. Decisions: DECISIONS 2026-11-03 "Cold-spray retrospective test: rules".

**Retrospective, not blind.** I have seen all measured windows while building the tables. This test checks
models and the judge's resolving power on existing data. It cannot show prediction of unseen materials; only
the blind campaign (go/no-go note, step 3) can.

## 2. Rules

- **P1 (properties):** matched source first. Hassani2020 Table S1, then the HG2018a preprint table, then
  handbook rows; field by field, with the source id recorded. Nothing is filled from memory. Bulk modulus
  B = E / (3(1 − 2ν)) from Table S1.
- **P2 (impact-fitted Y_d):** allowed, flagged as partly circular (fitted to sub-critical rebounds of the same
  campaigns).
- **Q (quantity):** single-impact v_cr at room temperature, as measured by LIPIT.
- **S1 (score):** d = 0 inside [v_low, v_high], else the distance to the nearest bound divided by the window
  midpoint.
- **S2:** in-domain and out-of-domain rows are reported separately; a model's domain claim is part of its
  definition (D1).
- **S3:** Q rows (conflicting secondary quotes) are not scored.
- **D1 (domain of the closed-form single-impact laws):** matched pair, room-temperature substrate, polished
  substrate, 8 ≤ d ≤ 16 µm.

  predicted_effect: [{metric: median d over held-out pure-metal in-domain rows, direction: down, size: "<= 0.05"}]

## 5. Judge-noise check (upgrade trigger, part 3)

Reported, not a hunch. On the held-out in-domain rows, count the rows where Z6_a015 and baseline_LOMO differ by
more than the row's window width (v_high − v_low). If fewer than half, the data cannot separate even a
property-based law from a constant, and the blind campaign must be designed for narrower windows or more
materials.
